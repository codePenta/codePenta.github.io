Datenschutzerklärung

Stand: September 2026

Pentas assistant ist ein privat betriebener Discord-Bot. Dieses Dokument beschreibt so genau wie möglich, welche Daten der Bot verarbeitet, wozu, und wie du sie wieder loswerden kannst.

Was gespeichert wird

Für die Willkommensnachrichten-Funktion speichert der Bot pro Server folgende Angaben, sobald ein Server-Administrator sie über /welcome set konfiguriert:

  • die Server-ID
  • die ID des gewählten Zielkanals
  • den frei formulierten Nachrichtentext

Diese Daten werden ausschließlich benötigt, um die konfigurierte Nachricht zu senden, wenn jemand dem Server beitritt.

Der Bot liest, speichert oder analysiert keine Nachrichteninhalte von Server-Mitgliedern und erstellt keine Nutzungsprofile.

Was nicht gespeichert wird

Keine Chat-Nachrichten, keine E-Mail-Adressen, keine IP-Adressen, keine Nutzungsstatistiken. Weitere Bot-Funktionen speichern nur das, was für ihren jeweiligen Zweck direkt nötig ist; diese Seite wird bei neuen Funktionen aktualisiert.

Wo die Daten liegen

Alle Daten liegen in einer selbst betriebenen Datenbank, nicht bei einem Drittanbieter. Es findet keine Weitergabe an Dritte statt, mit Ausnahme dessen, was für den Betrieb technisch zwingend über Discords eigene Infrastruktur läuft.

Löschung

Ein Server-Administrator kann die Konfiguration jederzeit selbst per /welcome off löschen, das entfernt die gespeicherten Daten sofort. Entfernt der Bot einen Server oder wird er dort entfernt, werden die zugehörigen Daten ebenfalls gelöscht.
